# Looking to add your game?

Create a Pull Request and add your game as `src/data/<Your Name or Studio Name>/<Your Game Name>.json`. The folder is the developer name and the file name is the game name. For both names, include the spaces and proper capitalization (look at the other games for examples). The image must be hosted somewhere else and be provided a valid URL.

The JSON data you must fully include. Nothing more and nothing less.

```json
{
	"developer": "Your Studio or Dev Name",
	"title": "Your Game Title",
	"description": "Description of your game",
	"url": "https://example.com/your-game/",
	"image": "https://example.com/your-game/screenshot.png",
	"tags": []
}
```

Tags should be empty! Only Braymen adds them.

Curated lists will be done by me, but everyone who is approved, will be in the all games section.

Not every game will be accepted. Some of those reasons can be found below. It's a subjective list of games as well.

# What games will likely NOT be approved?

- Non-browser based games. You can be on Steam, but the link is for playable browser versions only. I prefer full games, but not a automatic deny if it is just a demo.
- Blatantly obvious vibe-coded games. If it looks vibe coded, it's probably vibe coded. You can use AI if you want, but if your whole game is vibe coded or your using AI generated content/assets, it won't be approved. There's a difference between vibe coding a whole game and using ai for coding sparingly.
- AI generated assets. No ai images, music, sounds, text. I can't always be accurate on this, but if it's obvious, it'll be denied.
