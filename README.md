# Looking to add your game?

Create a Pull Request and add in a image for your thumbnail in the src/images and than add your game data to src/data/Games.ts.

Not every game will be accepted. Curated lists will be done by me, but everyone who is approved, will be in the all games section.

# What games will likely NOT be approved?

- Non-browser based games. You can be on Steam, but the link is for browser versions.
- Blatant vibe-coded games. If it looks vibe coded, it's probably vibe coded. You can use AI if you want, but if your whole game is vibe coded or your using AI generated content/assets, it won't be approved
- AI generated assets. No ai images, music, sounds, text.
